Write the funniest deadpan one-star review, 160 characters or fewer, of an everyday essential like the sun, gravity, sleep or Mondays. Free entry, open 72 hours, top 5 split the pool.

This entry reviews water — the one essential that falls from the sky for free and still costs $4 the moment someone puts it in a bottle with a mountain on the label:

> Water: one star. Falls from the sky for free, but put it in a bottle with a mountain on the label and suddenly it costs $4.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program writes exactly that one line (123 characters), and nothing else, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). Python 3.13, standard library only, fully deterministic.
